# Sicherheitsmeldungen

Keine verwertbaren Sicherheitslücken öffentlich als Issue melden. Nutze GitHubs private Sicherheitsmeldung, sobald diese vom Product Owner aktiviert wurde; andernfalls einen privaten Kontaktweg zum Betreiber. Der verantwortliche Sicherheitskontakt muss vor dem öffentlichen Release ergänzt werden.

Unterstützte Version: derzeit nur der Entwicklungsstand auf main, kein für Produktion abgenommenes Release. Abhängigkeiten werden in CI geprüft. Geheimnisse bleiben außerhalb des Repositorys. Passwort plus TOTP sind für alle administrativen Konten Pflicht.
